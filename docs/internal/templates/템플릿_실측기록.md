```powershell

Pop-Location
backend\.venv\Scripts\python.exe scripts\verify_docs.py
Push-Location frontend; npm test; npm run build; Pop-Location
backend\.venv\Scripts\python.exe -m pytest --rootdir backend backend\tests\e2e -m e2e -v
```

기대값: READY / <n> passed, TOTAL <n>% / All checks passed / 문서 <n>개 위반 없음 / <n> passed·built / E2E <n> passed. 소요 약 <n>분.
pytest 는 **`backend` 디렉토리에서** 실행한다 — coverage 대상 경로가 그 기준이다.
