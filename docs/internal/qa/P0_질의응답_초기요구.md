## Q1. 프로젝트 착수 (2026-09-14)

> 원하는 유튜브 채널을 통해서 학습을 하기 위한 프로그램을 만들고 싶어. 이 프로그램을 만들기 위한 프로젝트를 수행할까해? 어떤 전략과 방식, 단계로 진행하면 될지 기획해서 나에게 제안해볼래?

> 특정 유튜브 채널을 선택하면, 해당 유튜브 채널의 롱폼 영상목록, 숏폼 영상목록을 추출하고, 각 영상에 대한 전체 스크립트도 추출하고, 해당 스크립트를 기반으로 내용 요약 및 중요 내용 도출. 스크립트는 영상에서 자체적으로 제공을 안해도 직접 음성으로부터 추출이 가능해야 함.

> [요약 기능은] 우선은 해당 기능은 나중에 추가할 수 있게 아키텍처를 잡아보자. 스크립트 뽑는 기능 구현 후 빌드 배포하고, 해당 기능은 버튼 또는 포맷만 만들어놓고 나중에 기능 추가해서 연결할 수 있는 방식으로 진행.

> 로컬 웹앱, 데스크톱 앱, 나중에는 스마트폰 앱으로까지 개발 가능해야 함. […] 한국어 채널, 채널당 수백 개 이하로 시작하는데, [다국어·수천 개]로 확장할 수 있는 구조로 설계.

**결정**: Python(FastAPI) 백엔드 · 로컬 faster-whisper(CPU, 외부 API 없음) · React 웹 → Tauri(데스크톱) → Capacitor(모바일) · 자동 요약은 v1 제외하고 슬롯만 · Phase 0~6 로드맵.
→ `docs/scope-definition.md` 1·2·7절, `docs/설계서_Architecture.md` 1·2절

## Q5. 수동 요약 흐름 (2026-09-14 Direct 리뷰)

> 추가로 변경할 내용이 있다면, 요약 및 핵심 도출 기능은 추후 구현을 하지만, 현재는 사용자가 직접 스크립트를 복사해서 각자 사용중인 AI 챗 서비스에 붙여넣기하고 요약 및 핵심 정보 기능을 받아서 그 정보를 붙여넣기 할 수 있도록 그 기능과 저장기능이 필요해.

> 즉, 스크립트를 추출하면, 버튼 클릭 하나로 해당 스크립트 '복사'가 되어야하고, 또 외부에서 요약 및 핵심 정리 한 글을 붙여놓을 '요약 및 정리' 메뉴와 저장 기능이 필요해.

**결정**: 자동 분석은 P5 그대로. **수동 흐름을 v1(P3)에 넣는다** — 원클릭 복사 + '요약 및 정리' 붙여넣기 저장(`analyses`, `analyzer_name="manual"`).
→ `docs/scope-definition.md` 2.3·2.4절, `constants.MANUAL_ANALYZER_NAME`. 복사 형식 상세는 `P3_질의응답_복사형식과요약비교.md`
