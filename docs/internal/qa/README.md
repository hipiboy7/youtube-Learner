# docs/internal/qa — 사용자 질의응답 기록

Phase 진행 중 **판단 근거가 된 사용자와의 문답**을 보존한다(`CLAUDE.md` 10절). Phase별 한 파일: `P{N}_질의응답_<주제>.md`.

## 왜 남기나

결정 자체는 `CLAUDE.md` 보류 결정 표·scope·설계서에 들어간다. 그러나 "왜 그렇게 결정했나"는 대화 속에 있고, 대화는 사라진다.
다음 Phase나 다음 사람이 같은 질문을 다시 하지 않게, 질문·답·결정을 그대로 옮긴다.

## 형식

```markdown
# P<N> 질의응답 — <주제>

- 일자: YYYY-MM-DD / 참여: 사용자, <LLM>
- 관련: <보류 결정 번호 / 문서 절>

## Q1. <질문 원문>
A. <답 요약 — 근거 문서 절>
→ 결정: <무엇으로 정했나. 미정이면 보류 결정 등재 번호>
```

## 파일

| 파일 | 내용 | 일자 |
|---|---|---|
| (없음) | Phase 0 의 결정은 기획서·프롬프트에 원문이 있어 별도 기록 없음 (`docs/prompts/phase0/`) | 2026-09-14 |
