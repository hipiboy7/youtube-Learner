## Q1. (사용자) Gemini 에 (a) 영상 URL 만 준 요약과 (b) 우리 프로토타입이 추출한 스크립트를 준 요약 — 어느 쪽이 뛰어난가? (요약 프롬프트 "영상 학습 아키텍트" 첨부)

A. (Claude) 실제 자막(`ko-orig`, 311 세그먼트, 13:46)을 받아 대조했다.
- 5단계 구조와 수치(45분·22~25문항·킬러 2~4·1문항 1분·20문제 20분·10분 휴식·학교 4개)는 **둘 다 일치**.
- (a) URL 판: 제목·길이(13:47)·게시일 정확, 섹션마다 `[MM:SS]` 구간 인용. 그러나 원문에 없는 교재 이름("쎈 B단계", "쎈/RPM")을 자연스럽게 **보강함**.
- (b) 스크립트 판: 원문에 없는 것을 넣지 않았고 재구성 밀도·함의·빈틈 지적이 더 구체적. 자동 자막 오인식("포스트" → 포스트잇)을 문맥으로 복원. 그러나 입력에 제목·길이·URL 이 없어 **제목을 지어내고 길이를 8~10분으로 추정**(실제 13:46), 타임스탬프 없이 복사돼 구간 인용 불가.
→ 판정: 내용 정확도는 동급, 차이는 입력 차이. (b)의 약점은 전부 복사 텍스트에 메타데이터·타임스탬프가 없어서 생겼다.
→ 결정: 복사 텍스트에 **메타데이터 머리말**(제목·채널·URL·길이·게시일·스크립트 출처·세그먼트 수·복사일) + **타임스탬프 기본 켬**.

## Q2. (사용자) 프로토타입에 바로 반영하고, 복사할 때 **프롬프트도 함께** 붙일 수 있게 하고, **프롬프트를 수정할 수 있는 기능**도 필요하다.

A. (Claude) 프로토타입에 반영(2026-09-15).
- 복사 = `프롬프트 → 머리말 → [m:ss] 스크립트` 순서, 빈 줄로 구분. 세 요소 각각 체크박스로 켜고 끈다(기본 전부 켬).
- 프롬프트는 서버(`proto_settings`)에 저장 — 화면 "✏️ 프롬프트 편집"에서 수정·💾 저장·기본값 복원. 기본 템플릿은 사용자의 Gemini 프롬프트를 손본 것: "URL 접근·STT" 단계를 "머리말·스크립트를 신뢰, 미제공 항목은 추정 금지"로, 자동 자막 오인식은 복원 후 `[교정]` 표시, 원문에 없는 교재·수치 보강 금지.
→ 결정(P3 요구사항으로 승격): (1) 복사 형식 3요소와 기본값, (2) 프롬프트 템플릿 CRUD(저장·복원·편집본 표시), (3) 머리말은 "미제공" 표기로 지어냄 방지. 프롬프트를 여러 개 두는 것(용도별 템플릿)은 P3 프롬프트에서 질문.

## Q3. (Claude, 미결) 프롬프트 템플릿을 여러 개(요약용·Anki 용·짧은 요약용) 두고 고르게 할까, 하나만 둘까?

→ 결정: 미정.
