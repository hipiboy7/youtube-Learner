# docs/internal — 내부 작업 기록

이 디렉토리는 **작업 과정에서 만든 내부 자료**를 보관한다. 제출물(산출물)이 아니다.

## 산출물과의 경계

산출물은 `docs/` 최상위의 `scope-definition.md`, `설계서_Architecture.md`, `P{N}_요구사항정의서_*`, `P{N}_설계서_*`, `P{N}_테스트결과서_*`이며
**우리 판단의 근거만으로 서술**된다(`CLAUDE.md` 1절 "근거는 우리 것으로").
여기 있는 것은 그 판단에 이르기까지의 조사·점검·학습 자료다. 지우지 않는다 — 어떤 결정이 어떤 실측·점검을 거쳐 나왔는지 추적할 수 있어야 한다(`CLAUDE.md` 10절).

## 여기 없는 것

- **`docs/prompts/`** — 작업 프롬프트·기획서(요구사항 기록). 고치지 않고 버전을 올린다(`CLAUDE.md` 10절).
- **`history/`** — 세션 작업 기록. **사후에 고치지 않는다**(기록 위조).
- **`data/spike/`** — TechSpike 산출물(자막·오디오·결과 JSON). 저작물·용량 문제로 git 미추적. 재실행 명령은 TechSpike 7절.
