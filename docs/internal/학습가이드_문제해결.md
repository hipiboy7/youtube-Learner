## 0. 어떤 문제든 먼저 이것

```powershell
cd D:\claude\youtubeLearner

```

마지막 줄이 `==> READY` 면 프로그램이 돌 준비는 된 것이다. `[FAIL]` 줄이 있으면 그 줄이 무엇이 빠졌는지 말해 준다.
`[WARN]` 은 작업을 막지 않는다(디스크 여유, 아직 내려받지 않은 음성 인식 모델).

## 1. 증상별 표

| 화면·터미널에서 보이는 것 | 뜻 | 할 일 |
|---|---|---|
| 화면 위에 빨간 경고 "백엔드가 옛 버전입니다" | 프로그램의 옛 버전이 아직 돌고 있다 | 열려 있는 검은 창을 모두 닫고 실행 스크립트를 다시 실행한다. 스크립트가 남은 옛 프로그램을 정리한다 |
| "백엔드에 연결할 수 없습니다" | 프로그램 본체가 꺼져 있다 | 실행 스크립트를 실행한다. 검은 창 세 개가 열려야 정상이다 |
| 스크립트 상태가 "실패"이고 빨간 글씨가 보임 | 유튜브 요청이 막혔거나 음성 인식이 실패했다 | 빨간 글씨를 그대로 개발자에게 전달한다. 사유가 적혀 있다 |
| "스크립트 가져오기"가 10초 넘게 "진행 중" | 자막이 없어 음성 인식으로 넘어갔다 | 정상이다. 영상 길이의 절반 정도 기다린다(1시간 영상 ≈ 20분). 진행률 막대가 움직이는지 본다 |
| "클립보드 복사 실패" + 아래에 텍스트 상자 | 브라우저가 복사를 막았다 | 그 상자를 클릭하고 Ctrl+A, Ctrl+C 로 직접 복사한다 |
| 요약을 저장했는데 목록에 "요약 있음"이 안 보임 | 목록이 아직 갱신되지 않았다 | 브라우저를 새로 고친다. 그래도 없으면 개발자에게 전달 |
| 검은 창에 한글이 깨져 보이고 오류가 남 | 스크립트 파일 인코딩 문제 | 개발자에게 전달한다 (원인은 기록되어 있다 — T-005) |
| 디스크 여유가 부족하다는 경고 | 음성 인식 모델·오디오가 자리를 차지한다 | D 드라이브 여유를 확인한다. 부족하면 증설하거나 `data\proto\audio` 의 오디오 파일을 지운다(스크립트는 남는다) |

## 2. 프로그램 실행·종료

지금 화면이 도는 것은 **프로토타입 브랜치**(`prototype/e2e-slice`)뿐이다. 그 브랜치로 옮긴 뒤 실행 스크립트 `dev_proto.ps1` 을 실행하면 검은 창 세 개(토큰 서버 · 본체 · 화면)가 열린다.
정식 화면은 Phase 3 에서 만든다 — 그때 이 절의 명령을 실제 배포 경로로 바꾼다.

그다음 브라우저에서 `http://localhost:5173` 을 연다. 끝낼 때는 검은 창 세 개를 닫는다.

세 창이 각각 하는 일:

| 창 | 하는 일 | 꺼지면 |
|---|---|---|
| 첫 번째 (토큰 서버) | 유튜브가 요구하는 인증 토큰을 만든다 | 자막을 못 받거나 아주 느려진다 |
| 두 번째 (본체) | 목록·스크립트·저장을 담당한다 | 화면에 "연결할 수 없습니다" |
| 세 번째 (화면) | 브라우저 화면을 제공한다 | `localhost:5173` 이 열리지 않는다 |

## 3. 내 데이터는 어디 있나

| 무엇 | 위치 | 지워도 되나 |
|---|---|---|
| 채널·영상 목록, 스크립트, 요약 | `data\youtube_learner.db` | **안 된다** — 모든 기록이 여기 있다 |
| 유튜브에서 받은 자막 원본 | `data\proto\captions\` | 지워도 다시 받는다 |
| 음성 인식용 오디오 | `data\proto\audio\` | **지워도 된다** — 가장 자리를 많이 차지한다 |
| 음성 인식 모델 | `data\models\` | 지우면 다음 사용 시 다시 내려받는다(약 460MB) |

## 4. 개발자에게 전달할 것

문제를 알릴 때 아래 세 가지를 함께 주면 원인을 훨씬 빨리 찾는다.

1. 화면 위쪽 알림 문구 또는 빨간 글씨 **그대로**
2. `.\scripts\check_env.ps1` 출력 전체
3. 무엇을 누른 직후였는지 (예: "스크립트 가져오기를 누른 뒤")
